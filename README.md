# ระบบระเบียนขอเข้าฝึกปฏิบัติงาน (Elective)
## ศูนย์แพทยศาสตรศึกษาชั้นคลินิก โรงพยาบาลราชบุรี (Medical Education Center, Ratchaburi Hospital)

ระบบเว็บแอปพลิเคชันสำหรับบริหารจัดการและติดตามระเบียนการขอเข้าฝึกปฏิบัติงาน (Elective) ของนักศึกษาแพทย์, แพทย์ประจำบ้าน, และบุคลากรทางการแพทย์ ออกแบบตามโครงสร้างการทำงานจริงของโรงพยาบาลราชบุรี

---

### ✨ ฟังก์ชันสำคัญของระบบ

1. **ภาพรวมระบบสำหรับผู้บริหารและหัวหน้างาน (Supervisor Overview)**:
   - เห็นภาพรวมคำขอเข้าฝึกของทุกคนในระบบแบบง่ายและชัดเจน
   - สถิติ KPI สรุปยอด: คำขอทั้งหมด, รับเรื่องใหม่, ส่งกลุ่มงานแล้ว, รอกลุ่มงานตอบกลับ, ตอบรับเข้าฝึก, ปฏิเสธ, อัตราการตอบรับ (%)
   - กราฟสัดส่วนแยกตามกลุ่มงานในโรงพยาบาลราชบุรี (กุมารเวชกรรม, ศัลยกรรม, อายุรกรรม, สูติ-นรีเวชกรรม ฯลฯ)
   - สรุปภาระงาน (Workload) ของทีมงานแต่ละคน
   - ตาราง Master Table รวมทุกคำขอ พร้อมตัวกรองตามกลุ่มงาน, เจ้าหน้าที่, สถานะ และช่องค้นหา

2. **หน้าติดตามงานเฉพาะบุคคลของทีมงาน (Staff Kanban Board)**:
   - สลับแสดงผล "เฉพาะงานของฉัน" (My Tasks) หรือ "งานของทุกคน"
   - **Kanban Board 5 สถานะตามขั้นตอนจริง**:
     1. 📥 **รับเรื่องใหม่**: ได้รับหนังสือหรือคำขอ รอจัดทำบันทึกส่งต่อ
     2. 📤 **ส่งกลุ่มงานแล้ว**: ส่งหนังสือ/ประสานกลุ่มงานพิจารณาแล้ว
     3. ⏳ **รอกลุ่มงานตอบกลับ**: อยู่ระหว่างกลุ่มงานพิจารณาโควตาและอาจารย์แพทย์พี่เลี้ยง
     4. ✅ **ตอบรับเข้าฝึก**: กลุ่มงานอนุมัติตอบรับเข้าฝึกปฏิบัติงาน
     5. ❌ **ปฏิเสธ / ไม่รับ**: กลุ่มงานปฏิเสธเนื่องจากโควตาเต็มหรือไม่สะดวก
   - รองรับ **Drag & Drop (ลากวาง)** การ์ดเปลี่ยนสถานะ หรือคลิกปุ่มเลื่อนสถานะอย่างสะดวกรวดเร็ว
   - การ์ดแสดงข้อมูลครบถ้วน: ชื่องาน, รหัสคำขอ, ผู้ขอฝึก, สถาบัน, วันที่ขอฝึก, กลุ่มงาน, วันที่ส่ง, วันที่ตอบกลับ, สถานะตอบรับ, ผู้รับผิดชอบ และจำนวนไฟล์แนบ

3. **ข้อมูลในแต่ละงานและการจัดการรายละเอียด (Request Details & Routing)**:
   - ชื่องาน และหัวข้อการขอเข้าฝึก (มีปุ่ม ✨ ตั้งชื่ออัตโนมัติ)
   - รายละเอียดและวัตถุประสงค์การขอฝึก
   - วันที่ขอเข้าฝึกปฏิบัติงาน (ช่วงวันที่ เริ่มต้น - สิ้นสุด)
   - กลุ่มงานที่ขอเข้าฝึกปฏิบัติ (พร้อมชื่อหัวหน้ากลุ่มงานและผู้ประสานงาน)
   - วันที่ส่งให้กลุ่มงาน (Sent date)
   - วันที่กลุ่มงานตอบกลับ (Reply date)
   - สถานะการตอบรับ (รับ / ปฏิเสธ / รอผล) พร้อมระบุเหตุผล/เงื่อนไข
   - ผู้รับผิดชอบงาน (Assigned Staff)
   - บันทึกหมายเหตุเพิ่มเติมและประวัติการดำเนินงาน (Activity Timeline)

4. **ระบบอัปโหลดและแนบไฟล์เอกสาร (Attachments Management)**:
   - สามารถอัปโหลดได้ทันทีตอนบันทึก หรือ **อัปโหลดเพิ่มเติมภายหลังได้ทุกเมื่อ**
   - รองรับไฟล์ PDF, Word (.doc, .docx), รูปภาพ (PNG, JPG)
   - ระบุประเภทเอกสารได้ (เช่น หนังสือขอเข้าฝึก, หนังสือตอบรับ, ประวัติ/CV, เอกสารอนุมัติ)
   - มีปุ่มเปิดดู / ดาวน์โหลด และปุ่มลบไฟล์แนบ

5. **การจัดการสิทธิ์และข้อมูลผู้ใช้งาน (User, Username & Password Management)**:
   - **Admin (ผู้ดูแลระบบ)**:
     - **เพิ่มผู้ใช้งานใหม่**: กรอกข้อมูลบุคคล กำหนดบทบาทสิทธิ์ (`Admin`, `หัวหน้างาน`, `ทีมงาน`) พร้อมระบุ **Username** และ **Password** ที่ต้องการ (มีปุ่ม 🎲 สุ่มรหัสผ่านอัตโนมัติ)
     - **แก้ไขและเปลี่ยน Username**: แอดมินสามารถเข้ามาแก้ไขหรือเปลี่ยน Username ของผู้ใช้แต่ละคนได้ตลอดเวลา (พร้อมระบบตรวจสอบความซ้ำซ้อน)
     - **ดูและรีเซ็ตรหัสผ่าน (Password)**: แสดงรหัสผ่านในรูปแบบซ่อน `••••••••` พร้อมปุ่มรูปดวงตา 👁️ ให้แอดมินคลิกเปิดดูรหัสผ่าน และมีปุ่มลัด **"🔑 รหัสผ่าน"** เพื่อรีเซ็ตหรือเปลี่ยนรหัสผ่านใหม่ได้ทันทีในคลิกเดียว
     - **ลบข้อมูลผู้ใช้งาน**: มีปุ่มลบผู้ใช้ (🗑️) พร้อมหน้าต่างยืนยันการลบอย่างละเอียด โดยระบบจะลบข้อมูลผู้ใช้ Username และ Password ออกอย่างถาวร พร้อมปลดการมอบหมายงานค้างให้เป็น "ยังไม่มอบหมาย" อัตโนมัติ (และป้องกันไม่ให้ลบบัญชีตนเอง)
   - **User ของทีม**: สามารถเปิดหน้า **Profile** เพื่อแก้ไขข้อมูลส่วนตัวของตนเองได้ (ชื่อ-นามสกุล, ตำแหน่ง, เบอร์โทร, อีเมล, รูปไอคอน, เปลี่ยนรหัสผ่าน)
   - **สลับบทบาททดสอบ (Quick Role Switcher)**: ด้านบนของระบบมีแถบสลับสวมบทบาทระหว่าง Admin, หัวหน้างาน, และทีมงานแต่ละคนได้ทันทีโดยไม่ต้องล็อกเอาต์ซ้ำซ้อน

6. **การส่งออกรายงาน (Export Report)**:
   - รองรับการดาวน์โหลดรายงานสรุปเป็นไฟล์ CSV (รองรับภาษาไทย UTF-8 BOM เปิดใน Microsoft Excel ได้อย่างถูกต้อง)

### 💻 บัญชีผู้ใช้งานเริ่มต้นสำหรับทดสอบ (Pre-seeded Accounts)

| Username | ชื่อ - นามสกุล | บทบาท (Role) | ตำแหน่ง |
|---|---|---|---|
| `admin` | นพ. วิศรุต ปัญญาวงศ์ | **Admin** (ผู้ดูแลระบบ) | ผู้อำนวยการศูนย์แพทยศาสตรศึกษาชั้นคลินิก |
| `supervisor` | พว. รัตนาภรณ์ สมบูรณ์ทรัพย์ | **Supervisor** (หัวหน้างาน) | หัวหน้างานบริหารแพทยศาสตรศึกษา |
| `staff1` | น.ส. กัลยาณี เจริญผล | **Staff** (ทีมงาน) | นักวิชาการศึกษาชำนาญการ |
| `staff2` | นาย ธนกร วงศ์วิริยะ | **Staff** (ทีมงาน) | เจ้าหน้าที่ธุรการประสานงานฝึกอบรม |
| `staff3` | น.ส. ศิริพร บุญสว่าง | **Staff** (ทีมงาน) | นักวิเคราะห์นโยบายและแผน |

*(รหัสผ่านเริ่มต้นของทุกบัญชี: `password123`)*

### 🚀 วิธีการรันระบบ

เปิด Terminal ในโฟลเดอร์โครงการ แล้วใช้คำสั่ง:

```bash
# รันโหมด Production (ที่กำลังทำงานอยู่ ณ ปัจจุบันบนพอร์ต 3000)
npm run start

# หรือ รันโหมด Development สำหรับพัฒนาต่อ
npm run dev
```

เปิดเว็บเบราว์เซอร์ไปที่: **http://localhost:3000**
